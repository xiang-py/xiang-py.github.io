# Photography images

Place photography images in this directory, then group them into albums in `_data/photography.yml`.

Each album has one shared title, date, location, and description. Individual photos only need an image path and accessible `alt` text; captions are optional.

Set `photos_per_page` at the top of `_data/photography.yml` to control the photography page size.

Use short, descriptive, lowercase filenames such as `2026-07-shanghai-01.jpg`.
